# MatChat — GitHub Easy

Это упрощённая версия MatChat, специально подготовленная для загрузки в GitHub с телефона и бесплатного запуска на Render.

Файлы в корне:
- `server.js` — сервер и интерфейс MatChat
- `package.json` — зависимости и запуск
- `render.yaml` — настройки Render
- `README.md` — инструкция

Важно: это демо-прототип. Сообщения и пользователи хранятся в памяти и пропадут после перезапуска сервера. Реальная email-авторизация, база данных, загрузка файлов и push-уведомления требуют отдельных сервисов.
